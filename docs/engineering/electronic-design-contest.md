# 电子设计竞赛：FPGA 高速数据采集与显示系统

## 分工与总体方案

题目的大方向是「采集—处理—显示」，我们把它拆成两块：

- **FPGA**：ADC 接口、触发判断、数据缓存、波形渲染
- **MCU**：按键、菜单、参数下发、屏幕控制

这样分工的好处是 FPGA 只管确定性时序，MCU 只管交互，两边通过一组简单的寄存器接口通信。

## 数据通路

```text
ADC ──▶ 采样对齐 ──▶ 触发检测 ──▶ 双端口 RAM ──▶ 抽点 ──▶ 显示缓存
                                        │
                                        └──▶ MCU 读数（低速路径）
```

## 关键问题

### 跨时钟域

ADC 采样时钟和显示时钟完全异步。最初的写法是把采样数据直接给显示侧用，结果屏幕上偶尔出现整帧错位。

后来改成：

1. 采样数据先写入异步 FIFO
2. 读写指针格雷码化后再跨时钟域
3. 显示侧只在 FIFO 非空时取数

```verilog
// 格雷码转换：跨时钟域时只允许一位变化
assign gray = bin ^ (bin >> 1);
```

### 存储带宽

屏幕刷新需要在一帧时间内读完整个缓存，而采样又必须连续写入。单口 RAM 撑不住，换成**双端口 RAM + 乒乓缓冲**：一块写、一块读，每帧交换一次。

### 触发

边沿触发好做，难的是**预触发**：要保留触发点之前的一段数据。做法是环形缓冲，触发到来时只标记位置，等采满后再按标记顺序读出。

## 复盘

- 先把数据通路画清楚再写代码，比边写边改省时间
- 时序问题一定要上板验证，仿真里「看起来对」不等于板子上对
- 预留调试接口（比如把内部计数器引到 LED）比事后猜问题高效得多

最后系统完成了要求的采集与显示功能，指标满足题目要求。
