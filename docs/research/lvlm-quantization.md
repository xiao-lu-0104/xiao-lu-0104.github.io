# LVLM 量化入门：问题、难点与我目前的阅读路线

## 为什么要量化 LVLM

大型视觉语言模型（Large Vision-Language Model, LVLM）通常由三部分组成：

```text
图像编码器（ViT） ──▶ 投影层 ──▶ 大语言模型（LLM）
```

参数量和显存开销主要来自 LLM 部分。把权重和激活从 FP16 压到低比特，可以直接降低显存占用、提升推理吞吐，是部署阶段最实用的加速手段之一。

## 和只量化 LLM 有什么不同

LVLM 量化的难点并不只是「多了一个 ViT」：

| 难点 | 说明 |
| --- | --- |
| 模态差异 | 视觉 token 和文本 token 的数值分布差别很大 |
| 敏感层差异 | 不同层对量化的敏感程度不同，视觉相关层往往更脆弱 |
| 激活离群值 | LLM 里常见的激活离群值问题在 LVLM 中依然存在 |
| 校准数据 | 需要同时覆盖图像和文本模态 |

## 主流量化思路

### 1. 训练后量化（PTQ）

不重新训练，只用少量校准数据估计量化参数。优点是成本低，缺点是低比特下精度损失明显。

### 2. 量化感知训练（QAT）

在训练中模拟量化误差，精度更好，但需要训练资源和数据。

### 3. 细粒度 / 重要性感知

把「所有层一视同仁」改成「按重要性分配比特」。这也是我目前最感兴趣的方向：**哪些层、哪些通道对量化更敏感，能不能自动找出来**。

## 我目前的阅读路线

1. 先补基础：LLM 量化的经典工作（GPTQ / AWQ / SmoothQuant 系列）
2. 再看 LVLM 特有的问题：视觉 token 的分布、跨模态对齐对量化的影响
3. 最后跟最新的细粒度方法，尝试复现关键实验
